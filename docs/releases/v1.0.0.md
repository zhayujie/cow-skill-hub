# v1.0.0

Initial release of Cow Skill Hub — an open platform to discover, share, and install AI Agent Skills.

## Features

### Skill Browsing & Discovery
- Browse skills by category: **Recommended**, **Community**, and **Third-party**
- Filter by tags: Productivity, Development, Data Analysis, Content Creation, Research
- Search skills by name or description
- Paginated skill listing with responsive card layout

### Skill Detail Page
- View skill documentation (rendered Markdown)
- Browse skill file contents with expand/collapse
- Copy install command with one click
- Display required environment variables and dependencies
- Show skill metadata: version, source provider, author, tags

### Multi-Source Installation
- **Cow Skill Hub** — `cow skill install <name>`
- **GitHub** — `cow skill install github:<owner/repo>`
- **ClawHub** — `cow skill install clawhub:<name>`
- **LinkAI** — `cow skill install linkai:<code>`

### Skill Submission
- Submit skills via [skills.cowagent.ai/submit](https://skills.cowagent.ai/submit)
- OAuth login with GitHub and Google
- Upload folder or zip with `SKILL.md` at root
- Safety checks and review before publishing
